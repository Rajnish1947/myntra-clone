# 🛍️ Myntra Clone - Landing Page

A clean, responsive front-end clone of the Myntra landing page, built using **HTML**, **CSS**, and **Vanilla JS** (for the slider). This project replicates the layout and design style of Myntra's homepage, including a banner slider, navigation bar, search input, category section, and footer.

## 📸 Preview

[live Preview](https://rajnish1947.github.io/myntra-clone/)  
> *Fully responsive across desktop, tablet, and mobile screens.*

---

## ✨ Features

- ✅ Responsive header with logo, nav menu, search bar, and user actions
- 🎯 Animated **auto-playing banner slider**
- 🧩 Flexbox-based **category product grid**
- 📱 Mobile-friendly with smooth transitions
- 🧼 Clean UI and consistent styling with hover effects
- 🦶 Structured footer with useful links
